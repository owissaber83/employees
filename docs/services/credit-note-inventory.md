# حركات المخزون — الإشعار الدائن (Phase 7 Step D)

## 1. الاتجاه والغرض

مرتجع مبيعات ⇒ البضاعة **تعود** إلى المخزن: حركة `type: 'in'` بسبب `sales_return`.

## 2. التقييم — المتوسط المرجّح المتحرّك

```
calcItemMovingAvg(...).avgCost   إن > 0
  ←  item.costPrice
  ←  line.unitPrice
  ←  0
```

يُعاد استخدام `src/domain/inventory/movingAverage.js` المستخلَصة والمُثبتة في Step C —
**لا نسخة موازية من منطق التقييم** (§18 من تعليمات Step D).

**لماذا المتوسط لا سعر السطر:** سطر فاتورة المبيعات يحمل سعر **البيع**، فلا يصلح تكلفةً.
(الإشعار المدين يفعل العكس لسبب معاكس — راجع [`debit-note-inventory.md`](debit-note-inventory.md).)

## 3. حقول الحركة — منقولة حرفياً

```
number      IN-{year}-{00001}   ← محجوز بمعاملة عدّاد
date        = تاريخ الإشعار
type        'in'        reason 'sales_return'
itemId      qty         (الصفر لا يُرفض)
unitPrice   = التكلفة أعلاه
projectId   = مشروع الإشعار ‖ ''
description 'مرتجع - إشعار دائن {رقم}[ - {وصف السطر}]'
sourceType  'credit_note'       sourceKey {مفتاح الإشعار}
createdAt   createdBy
```

⚠️ **غائب عمداً** (مطابقة للقديم، مُختبَرة): `warehouseId` · `salePrice` · `notes`.
حركة **البيع** تحمل `salePrice` و`notes`؛ حركة **المرتجع** لا تحملهما.

## 4. قواعد التخطّي — محفوظة حرفياً

| الحالة | السلوك | صنف |
|---|---|---|
| لا `itemId` | تخطٍّ | A |
| الصنف غير موجود | تخطٍّ | A |
| `item.type === 'service'` | تخطٍّ | A |
| كمّية صفر | **تُكتب حركة بصفر** | A |
| لا سطور إطلاقاً | لا حركات، والإشعار يصدر | A |

**لا فحص كفاية رصيد** — لا معنى له في حركة إدخال.

## 5. الاتساق مع القيد

| الحالة | النتيجة |
|---|---|
| نجاح | مستند + قيد + **كل** الحركات — كتابة ذرّية واحدة |
| فشل | لا مستند · لا قيد · لا حركة · الفاتورة معوَّضة |
| تكرار بنفس المفتاح | لا حركات إضافية |

القديم بالمقابل: كل حركة `push` مستقلّ داخل `try/catch` يبتلع الخطأ (`console.error` فقط)
⇒ فشل حركة واحدة يترك الإشعار صادراً بحركات ناقصة **بصمت** — نفس نمط BUG-009 في مسار
البيع. الخدمة الجديدة لا تُعيد إنتاجه (`failure [G·H·I]`).

## 6. حدود معروفة

1. **عدّاد الحركات لا يُبذَر** من لقطة المتصفّح كما في القديم — ترقيم لا مال (صنف B).
2. **N معاملة عدّاد** لكل إشعار — مصدر رئيسي لزمن الشبكة.
3. **التقييم O(سطور × حركات)** — كل سطر يُعيد مسح سجل الحركات. منقول حرفياً؛ التحسين
   مؤجَّل عمداً (الاستخلاص لا يُغيّر السلوك).
4. **لا قيد مخزون ولا تكلفة بضاعة مباعة** — النظام جرد دوري (D2، مُؤكَّد في Step C).
